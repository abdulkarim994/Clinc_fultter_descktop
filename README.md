# طب الأسنان الرقمي — نسخة Flutter

تطبيق إدارة عيادة أسنان يعمل **بلا اتصال أولاً**: كل جهاز يحتفظ بتاريخه
كاملاً محلياً، والمزامنة السحابية طبقة فوق ذلك لا شرط له. واجهة عربية RTL،
أندرويد وويندوز.

> نُقل عن تطبيق Vue أصلي. التعليقات في الشيفرة تشير إلى «التوأم» (النظير في
> الأصل) وإلى معالم مرقّمة (م1…م77) تسجّل سبب كل قرار وتاريخ كل إصلاح.

## تشغيل سريع

```bash
flutter pub get
flutter test          # 500+ اختباراً
flutter run           # وضع محلي: لا يحتاج سحابة
```

بلا إعداد سحابي يعمل التطبيق في **الوضع المحلي** (خادم مزيّف داخلي، بيانات
على الجهاز فقط). للبناء بسحابة حقيقية:

```bash
cp tool/cloud.env.example tool/cloud.env   # املأه بقيمك
./tool/build_cloud.sh
```

## قواعد المشروع

**تعليق عربي، معرّف إنجليزي.** مطبَّقة في كل ملف بلا استثناء.

**صفر `print` وصفر `debugPrint`.** بيانات المرضى لا تدخل السجلّات أبداً. وعند
الحاجة إلى تسجيل عطل يُستعمل `core/error_log.dart` — وهو **يحجب النصوص
العربية والأرقام الطويلة والبُنى الشبيهة بالبريد قبل الكتابة**، لأن رسائل
الاستثناءات تحمل أسماء مرضى.

**الأعلام أرقام لا منطقيات.** `isDebt` و`isPros` و`isDebtPayment` تُكتب `0`
أو `1` دائماً. كتابتها منطقيةً تُخزَّن في مخزن JSON وتُسقط تقارير الخادم
(م76). يفرضها حارس في `push.dart` وفحص في التكامل المستمر.

**كل كتابة تمرّ عبر مستودع.** لا كتابة مباشرة على القاعدة من طبقة الميزات —
المستودع يختم الساعة المنطقية وعلامة المزامنة، وتجاوزه يكسر المزامنة صامتاً.

## الحالة

اختبارات خضراء · تكامل مستمر في `.github/workflows/ci.yml` · قاعدة الإنتاج
نُظِّفت وحُصّنت في 2026-07-31.

**تشفير البيانات عند السكون — منجَز (م83).** القاعدة وصور الأشعة على
SQLCipher، والمفتاح في مخزن أسرار النظام.

> ⚠ **يغيّر قواعد النسخ الاحتياطي**: نسخُ ملف القاعدة لم يعد كافياً
> للاستعادة — المفتاح لا يُنسخ معه، والمزامنة السحابية هي النسخة الاحتياطية
> الحقيقية. اقرأ **`ENCRYPTION_AR.md`** قبل النشر.

**بنود سوبابيس الأربعة** (تدوير المفتاح، إغلاق التسجيل، تأكيد البريد،
حماية كلمات المرور المسرَّبة) **مقبولة المخاطر بقرار المالك** — والأساس
الفني مُتحقَّق منه بالتشغيل: لا جدول مكشوف عبر PostgREST، وكل دوال المزامنة
تحصر نتائجها بـ`auth.uid()` داخلها. التفصيل والأدلّة في قسم «قرار المالك»
من `SECURITY_RUNBOOK_AR.md`.

**البنود المتبقّية مرتَّبة بالأثر** في آخر `SECURITY_RUNBOOK_AR.md`. وأهمّها
الآن: **تدقيق عامل Cloudflare** — شيفرته خارج المستودع.
